# Skystore - Интернет-магазин цифровых товаров

![Django](https://img.shields.io/badge/Django-5.2.4-green)
![Python](https://img.shields.io/badge/Python-3.13+-blue)

Skystore - это веб-приложение для продажи цифровых товаров, таких как плагины, утилиты и примеры кода. Проект разработан на Django с использованием Bootstrap для фронтенда.

## Особенности проекта

- Чистый современный интерфейс с Bootstrap 5
- Две основные страницы: Главная и Контакты
- Адаптивный дизайн для всех устройств
- Форма обратной связи на странице контактов
- Готовые шаблоны для каталога товаров

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd skystore
Установите зависимости через Poetry:
~~~
poetry install
~~~

Примените миграции:
~~~
poetry run python manage.py migrate
~~~
Запустите сервер разработки:
~~~
poetry run python manage.py runserver
~~~
Откройте в браузере:

text
http://localhost:8000/        # Главная страница
http://localhost:8000/contacts/ # Контакты
